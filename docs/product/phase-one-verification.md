## 验证边界

- 默认 H2 本地模式完成真实启动与重启验证。
- PostgreSQL 适配复用相同 JDBC 仓储和事务；本环境没有 PostgreSQL/Docker，尚未进行真实 PostgreSQL 实例联调。
- 未调用真实 LLM 验收周报质量；完整周报任务、附件精确引用、DOCX/XLSX 输入和 Word/PDF 导出属于后续批次。
- 浏览器匿名身份由本机生成；换浏览器续接要求配置或登录到相同用户/工作区。
