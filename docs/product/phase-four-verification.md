# 第四批验证记录

验证范围：后台任务中心、办公平台连接、团队权限和真实用户试点数据闭环。

## 后台任务

- 周报生成通过持久化任务提交，任务状态包含排队、执行、成功、失败和取消。
- 任务记录进度、消息、输入载荷、结果、错误及起止时间；管理员可查看工作区任务，普通成员只能查看自己的任务。
- 排队或执行中的任务遇到服务重启会明确标记失败，可由用户重试，不会永久显示“执行中”。
- 连接同步检查复用同一任务中心；运行中任务支持取消，失败或取消任务支持重试。

## 办公平台连接

- 连接注册表覆盖 Microsoft 365、Google Workspace、飞书、钉钉、企业微信和手动上传。
- 数据库只保存 `env:`、`vault:` 或 `secret:` 凭证引用。请求中出现 token、secret、password 或 api_key 明文配置时服务端拒绝。
- 配置验证区分已连接和待授权，能力范围对用户可见；同步检查保留执行记录。
- 当前实现不伪造远端文件导入。真实文件同步仍要求部署环境提供平台凭证，并由相应平台授权范围驱动。

## 团队权限

- 空工作区的首位用户成为所有者；后续用户必须先受邀，邀请在首次登录时激活。
- 角色分为所有者、管理员、编辑者和只读成员。只读成员可查看但不能修改文档、周报或任务。
- 只有管理员可以管理连接和成员；只有所有者可以任命管理员或变更所有者角色。
- 服务端阻止停用或移除最后一名有效所有者，权限判断不依赖前端隐藏按钮。

## 试点闭环

- 自动记录周报开始、后台生成、定稿和导出事件，并计算完成时间和编辑行数。
- 成员可以提交 1 至 5 分评分、事实错误数和文字反馈。
- 管理员面板汇总完成周报、平均完成时间、平均修改量、事实错误率、次周复用率和平均评分。
- 仪表盘只展示实际事件，不创建模拟试点结果。真实用户招募、知情说明和实际观察属于部署后的运营活动。

## 自动化验证

- 后端测试覆盖所有者引导、受邀成员激活、只读拒绝、最后所有者保护、凭证引用、连接生命周期、后台任务完成和试点指标聚合。
- 前端端到端测试覆盖任务查看、连接创建、成员邀请、试点指标和反馈提交，并在桌面、平板和手机视口执行。
