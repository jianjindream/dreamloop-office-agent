# 第三批验证记录

验证范围：DOCX/XLSX 输入、确定性计算、资料冲突与缺项、公司模板、审阅差异、完整周报任务和 Word/PDF 导出。

## 已实现能力

- 上传解析：DOCX 按正文顺序输出段落和表格定位；XLSX 输出工作表、行号和公式求值后的显示值。原始附件仍单独保存。
- 周报任务：项目、周期、模板和资料范围均为服务端必填项，最多选择 20 份资料，并校验工作区归属。
- 事实审阅：完成、进行中、风险和计划按资料提取；本期外完成事项不会进入本周完成。
- 数值计算：缺陷关闭比例由已关闭数除以计划总数计算，同时返回输入、公式、结果和来源；分母为零时不生成伪结果。
- 冲突与缺项：缺陷数、负责人和日期出现多值时保留所有资料值；未发现完成事项或资料明确写明未确认时进入待确认清单。
- 模板：提供内置标准模板；自定义模板作为工作区文档持久化并受相同归属控制。
- 审阅：生成结果保存为草稿，用户修改后可查看逐行新增/删除，再保存为新的不可变正式版本。
- 导出：可按指定版本导出 DOCX 或 PDF；Docker 运行镜像安装 Noto CJK 字体，Windows 本地使用系统中文字体。

## 自动化验证

- 后端单元测试覆盖 DOCX 表格、XLSX 公式、周期过滤、确定性计算、资料冲突、行级差异和 DOCX/PDF 重开读取。
- 前端端到端测试覆盖周报范围选择、生成、问题审阅、修改差异和正式保存。
- Word 导出通过 Apache POI 重开并检查标题和表格；PDF 通过 PDFBox 重开、文本抽取，并使用 Poppler 渲染逐页检查中文、换行和版面。

## 当前环境说明

当前 Codex 捆绑运行时未提供 LibreOffice，因此本地自动化无法执行 DOCX 到 PNG 的独立渲染复核。DOCX 已完成 OOXML 重开结构校验，PDF 已完成逐页视觉检查；CI 或验收环境安装 LibreOffice 后应继续运行 DOCX 渲染门禁。
