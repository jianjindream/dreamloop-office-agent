# 第二批验收记录

第二批范围：附件与提问绑定、资料范围约束、办公意图路由、原文引用定位。

## 已交付

- 上传附件返回的 `document_id` 随下一次聊天请求发送；成功发送后清除，不会隐式影响后续提问。
- 支持 `none`、`workspace`、`selected` 三种资料范围。精确范围最多 20 份资料，后端重新校验所有权、删除状态与当前索引状态。
- 路由可识别问答、总结、比对、提取、润色、写作和分析。精确资料范围优先于“查询/是什么”等宽泛工具关键词。
- RAG 上下文使用稳定的 `[S1]` 编号，提示要求事实、数字和结论逐项引用，并明确暴露缺项与冲突。
- 引用结构包含文档 ID、标题、不可变版本 ID/版本号、稳定父片段号、原文摘录、相关度和检索来源。
- 助手消息引用写入服务端历史；重新加载或更换浏览器后可恢复。点击引用打开当时参与回答的历史版本。

## 安全与边界

- 客户端只能传文档 ID，不能传可信索引哈希；跨工作区或跨用户读取返回文档不存在。
- 未完成索引的资料不会悄悄扩大到工作区范围，而是返回 `DOCUMENT_NOT_INDEXED`。
- 当前定位粒度为文本切分后的稳定“原文片段”，不是 PDF 页码或 Word 段落号；DOCX/XLSX、页码/单元格定位属于第三批解析能力。
- 当前真实模型的引用遵循度仍取决于所接入模型；结构化引用列表始终由实际检索结果生成，不依赖模型自报来源。

- 前端覆盖：用户身份范围内的资料选择持久化、服务端历史恢复；生产构建进行 TypeScript 校验。
